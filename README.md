# 웹 모션 가이드

**웹사이트의 움직임을 보고, 원하는 효과를 AI에 요청하세요.**

웹사이트를 만들 때 원하는 움직임은 떠오르지만 어떻게 설명해야 할지 막막한 분을 위한 한국어 가이드입니다. 모션 예시를 보고 효과를 고른 다음, AI 코딩 도구에 전달할 요청문을 복사할 수 있습니다.

**[웹 모션 가이드 열기 →](https://foodie-repository.github.io/web-keyword-graphic/)**

## 이렇게 사용하세요

1. 첫 화면의 움직이는 카드에서 원하는 효과를 고릅니다. 그룹 바로가기로 기본 움직임, 글자와 그림, 화면과 마우스 효과를 살펴볼 수 있습니다.
2. 카드를 누르면 확대 예시와 요청문이 열립니다. 효과를 빠르게 전달하려면 **짧은 요청**, 시작 조건·속도·완료 후 상태까지 지정하려면 **자세한 요청**을 선택합니다.
3. 요청문 하나를 복사해 사용 중인 AI 코딩 도구에 붙여 넣고, 적용할 페이지·문구·요소를 자신의 프로젝트에 맞게 덧붙입니다.
4. 차이를 더 알고 싶으면 쉬운 설명과 비슷한 효과를 읽거나, 하단의 **직접 비교해 보기**를 펼칩니다. 대표 실습에서는 설정을 바꾸고 현재 설정의 요청문을 복사할 수 있습니다.

예를 들어 [타이핑 효과](https://foodie-repository.github.io/web-keyword-graphic/#/typewriter)를 열어 짧은 요청을 복사한 뒤, 자신의 웹사이트에서 어떤 제목에 적용할지 함께 알려 주세요. 요청문은 구현을 돕는 예시이며, 적용 후에는 프로젝트의 화면과 모바일 동작을 확인해야 합니다.

## 무엇을 볼 수 있나요?

| 구성 | 내용 |
|---|---|
| 모션 치트시트 | 첫 화면의 24개 움직이는 카드 |
| 적용 가이드 | 추가 바로가기를 포함한 26개 가이드와 짧은·자세한 요청문 52개 |
| 전체 용어 찾기 | 16개 분야의 웹 디자인·개발 용어 360개 |
| 직접 비교해 보기 | 학습 시연 65개와 대표 설정의 비교·설명 |

대표 비교 실습은 타이핑, 가감속, 반응형 배치, 마그네틱 버튼, 행간입니다. 로그인이나 설치 없이 브라우저에서 사용할 수 있습니다.

## 움직임과 모바일 이용 안내

첫 화면의 모션은 효과를 보여 주는 자동 예시입니다. 실제 마우스·스크롤 조작을 설명용으로 연출하는 카드도 있습니다. ‘모션 모두 멈춤’으로 정지할 수 있으며 운영체제의 동작 줄이기 설정을 지원합니다. 모바일에서는 포인터 효과를 정적인 대체 동작으로 보여 줄 수 있습니다.

데스크톱과 390px·320px의 터치 에뮬레이션에서 탐색·요청문 복사·배포 자산을 검증했습니다. 실제 휴대전화와 Safari 전체 동작을 검증한 것으로 보지는 않습니다. 학습 시연의 저장·신청·결제 등은 설명을 위한 모형입니다.

## 이 저장소에 관하여

이 저장소는 **GitHub Pages 공개 배포용**입니다. 실행에 필요한 정적 빌드 파일과 공개 안내 문서를 관리하며, React·TypeScript 개발 원본과 내부 작업 문서는 포함하지 않습니다. 따라서 이 저장소를 복제해 `npm install`이나 `npm run dev`로 개발하는 구조는 아닙니다.

사이트는 Vite·React·TypeScript로 제작했으며 `/web-keyword-graphic/` 경로에서 동작합니다. [deployment.json](deployment.json)에는 앱 빌드의 원본 커밋과 배포 정보가 있습니다. 공개 문서만 수정한 커밋은 앱 빌드의 변경과 구분합니다. 배포 파일을 다루는 작업 지침은 [AGENTS.md](AGENTS.md)에 있습니다.
