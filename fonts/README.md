# 시연용 Abel 글꼴

Abel-Regular.ttf는 Google Fonts 저장소의 원본 파일이다. 타이포그래피 시연의 영문 비교에만 사용하며 사이트 전체 글꼴은 변경하지 않는다. 브라우저는 이 프로젝트의 로컬 경로에서 파일을 읽으며 Google Fonts 서버에 요청하지 않는다.

- 출처: https://github.com/google/fonts/tree/main/ofl/abel
- 원본 파일: https://raw.githubusercontent.com/google/fonts/main/ofl/abel/Abel-Regular.ttf
- 내려받은 날짜: 2026-10-29
- 저작권: Copyright (c) 2011, Matthew Desmond. Reserved Font Name Abel.
- 라이선스: SIL Open Font License 1.1. 원문은 Abel-OFL.txt에 보존한다.
- 글꼴 SHA-256: 8809dcad25318225052f88333e208c5aad4adcb7b2c934c135735ec19aa410b4
- 라이선스 SHA-256: 4f4bc3806a1e55789c6ef75ca5fc628297b05292f74966474dc0d40324abc609

파일을 수정하거나 다른 글꼴로 바꾼 경우 이 기록도 실제 파일에 맞게 갱신한다.
